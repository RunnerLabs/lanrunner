Chat local. Private. Nothing in the middle.

Lan Runner finds nearby devices on the same LAN and opens encrypted peer-to-peer chat sessions. No account, no central server, no internet required.

Start in three steps

01
Install or extract

Use the correct build for each device.

02
Start Lan Runner

The interface opens locally in your browser.

03
Allow the private network

Keep UDP 47100 and TCP 47101 open inbound.

Peer visible but timing out?

Allow inbound TCP 47101 on that peer. If nobody appears, confirm both devices share the same non-guest Wi‑Fi and allow UDP 47100.

Sending a guest kit to a phone?

Use the QR code, not the file. iOS previews a downloaded HTML file instead of running it, so the folder only works on a computer.

Private-network ports

peer discovery / inbound UDP47100
encrypted messaging / inbound TCP47101
browser interface / loopback only8080
guest kits / inbound TCP, only while an invite exists47102
guest kits over HTTPS / phones, same condition47103
